# 黑盒解谜 · 部署与赚钱手册

## 在线试玩（3D 猫咪小屋版）
选一只猫在屋里乱逛，靠近发光的黑盒子按 E 开盒试探——屋里有 3 个盒子，
规律各不相同（质数 / 偶数 / 平方数），全部破解即通关。
手机拖左侧摇杆移动、点"开盒"按钮试探。
> 试玩地址：https://haff981.github.io/blackbox-demo/（`classic.html` 为 2D 经典版）

## 这是什么
一个"链上黑盒解谜"游戏网站。出题人（你）在 TapeOut 上流片一颗真实电路，
玩家免费试探输入输出、猜它的逻辑功能，付门票提交答案哈希上链，猜中分奖池。

## 上线三步（v1 是纯静态站，不需要买贵的服务器）

### 1. 服务器 + 域名（一年 60 块就能开张）
- **最省方案**：Cloudflare Pages / Vercel 免费托管静态文件 + 一个域名（约 60 元/年）。
  把 `blackbox/` 文件夹里 6 个文件传上去，绑定域名即可。
- 备选：腾讯云/阿里云轻量服务器（2核2G，一年约 100~200 元），用 Nginx 托管静态文件。
- v1 不需要数据库、不需要后端 —— 链（BSC）就是数据库。

### 2. 改 config.js（开赛前必做）
| 项 | 说明 |
|---|---|
| `poolAddress` | 换成你的**奖池钱包地址**（新建单独钱包，只放奖池的钱） |
| `roundEnd` | 本轮截止时间戳 |
| `ticketBNB` | 门票价，默认 0.02 BNB |
| `bscscanApiKey` | 去 bscscan.com 申请免费 Key，"探子榜"靠它读链 |
| `circuit` | 你流片出真实电路后：`mode:"onchain"`，填合约地址 + ABI + 查询方法名 |

### 3. 出题（在 TapeOut 上）
1. 在 tapeout.net/#canvas 设计一颗"有趣但可解"的电路（4~8 位输入、1 位输出最佳，
   比如：质数判定、回文判定、海明重量谜题……别太难，第一期要让人能猜中）。
2. 流片 → 得到 Circuit NFT（TapeID）。
3. 把合约地址填进 `config.js`，网站试探台就直连链上黑盒了。
4. 在 X 上发开赛推文（boone 可以帮你写）。

## 怎么赚钱（5 条收入线）

### ① 门票（核心收入）
- 定价：0.02 BNB/次（约 $13），每钱包限 3 次。
- 奖池分配：**70% 冠军 · 20% 归你 · 10% 滚入下期**。
- 测算：一期 200 人次提交 → 4 BNB 奖池 → 你拿 **0.8 BNB（约 $500+）**，冠军拿 2.8 BNB。
  每周一期，一个月 4 期 ≈ **$2000+**。流量起来后门票可涨到 0.05 BNB。

### ② Hint 商店（纯利润，v2 加）
- 0.05 BNB 解锁"真值表中的一行"、0.1 BNB 看"电路用了多少个门"。
- 实现：在网站加个付费按钮，付款后前端展示提示。零成本。

### ③ 冠名赞助（流量起来后）
- 一期冠名 "本期由 XX 赞助"，收 0.5~2 BNB。Meme 项目方最爱这种曝光，
  顺带让他们把题目做成自己代币相关的电路，双赢。

### ④ Circuit NFT 本身
- 揭晓后，这枚"史上第一颗黑盒芯片"NFT 自带故事，挂出去拍卖。
  玩家会为"我解开的那颗芯片"付收藏溢价。

### ⑤ 复制模式（长期）
- 跑通后给别的项目方"代办黑盒赛"收服务费，或收季票/会员。
- 你的 X 人设（扒皮/锐评）+ 每周直播"逆向黑盒" = 内容飞轮，网站是变现终端。

## 成本
- 首期**零奖金成本**：奖池全部来自门票，你一分钱不用出。
- 流片成本：BSC 上铸造晶体管 + 流片 Gas，约几美元。
- 服务器+域名：一年约 60~200 元。

## 风险提示
- 第一期必须有人猜中（题目别太难），否则"有去无回"会劝退玩家。
- 奖池钱包的私钥自己保管好，这是唯一的资金风险点。
- v1 发奖是手动的（网站标出 Winner，你转账），跑通后再考虑自动发奖合约。
